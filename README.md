# 朝夕

朝夕是一款轻量、安静的个人日程工作台。它将最近待办、重要时间段、月历与每日手记放在同一个界面，帮助你快速看清接下来要做什么、哪些时段不能错过。

直接在线使用：

https://yaohuan1120.github.io/zhaoxi/

无需注册、下载或安装。

## 开始使用

1. 打开网站，在“工作台”中添加最近待办、长期待办或重要时间段。
2. 点击事项可修改内容；勾选框可随时标记完成。
3. 有日期的待办和重要时间段会自动同步到“日历”。
4. 点击左下角“设置”，按偏好选择主题、字体、字号与背景。

首次打开时，朝夕会提供一组示例事项，方便了解不同日期、时刻与多日时间段的展示方式；你可以直接编辑或删除它们。

## 工作台

工作台将近期安排分为三个区域：

- **最近待办**：记录近期要完成的事项。带日期或时刻的事项会按时间靠前排列；只有标题的事项排在其后。事项集中显示在随主题变化的浅色列表中，便于扫读。
- **重要时间段**：用于课程选课、报名、考试、项目周期等有明确开始与结束时间的安排。展示倒计时、名称和完整起止时间；可视区域固定为三行，更多内容可通过右侧滚动查看。
- **长期待办**：存放长期目标或暂不需要立即处理的计划。长期待办不会进入最近待办或日历时间安排。

右上角的“查看日历”可直接切换到月历。

## 日历

日历以月视图集中展示待办与重要时间段。

- 使用左右按钮切换月份，点击“今天”快速回到本月。
- 点击日期空白处即可新建待办；点击已有待办或时间条可编辑。
- 带日期的待办会显示在对应日期格内，完成状态与工作台同步。
- 多日的重要时间段会显示为连续的彩色时间条；相邻时间条会使用不同颜色，帮助区分重叠安排。
- 时间条会反映当天的开始与结束时刻：午后开始从日期格中部起，午前结束在日期格中部结束；开始端显示开始时刻，结束端显示结束时刻。
- 某一周有较多时间段时，日期行会自动增加高度，避免文字重叠或遗漏。

## 日志

日志用于保存每日手记。

- 可按日期浏览和书写标题、正文。
- 内容会自动保存在当前设备，无需手动提交。
- “时光倒流”可随机打开一篇已写过的往日记录，也能随时回到今天继续书写。

## 个性化设置

- **主题设计**：提供蓝、绿、紫、黄、粉、橙、青与深色主题；导航、强调文字、浅色列表和日历时间条会同步协调变化。
- **字体设计**：可选择雅黑、圆体、宋体或楷体，并为中文、英文和数字匹配协调的字形。
- **字号大小**：可在 90%–110% 范围内调节全站字号，列表的行距会随之保持紧凑。
- **工作区背景**：可从内置默认背景中选择，也可上传本地图片、裁剪画面并缩放。背景仅用于右侧工作区，系统会加柔光层以保持文字清晰。

## 手机使用

直接在手机浏览器中打开即可使用：

https://yaohuan1120.github.io/zhaoxi/

移动端导航会收起为菜单；待办与重要时间段会针对窄屏调整信息排布，重要时间段的完整起止时间可横向查看。

## 数据保存与隐私

朝夕目前是纯前端网页。待办、重要时间段、日志和个性化设置均保存于**当前设备、当前浏览器**的网站本地数据中，不会上传到服务器。

- 关闭网页后，在同一浏览器重新打开，内容仍会保留。
- 更换设备或浏览器、使用无痕窗口，或清除该网站的浏览器数据后，内容无法自动恢复。
- 在线版与本地调试版的保存位置彼此独立。

重要内容建议另行备份。

## 本地运行

下载或克隆项目后，直接用浏览器打开 `index.html` 即可使用；也可以通过任意静态文件服务器运行。
