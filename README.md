# 朝夕

朝夕是一款轻量、安静的个人日程工作台，把近期待办、重要时间段、日历和每日手记放在同一个页面中。

直接在线使用：https://yaohuan1120.github.io/zhaoxi/ 。无需注册、下载或安装。

## 开始使用

1. 打开网站后，从“工作台”开始添加最近待办、长期待办或重要时间段。
2. 有具体日期的待办会自动出现在“接下来”和“日历”中；勾选完成状态会同步更新。
3. 在“日志”中随手记录当天想法，内容会在输入时自动保存。
4. 点击左下角“设置”，可按自己的偏好调整主题、字体、字号和工作区背景。

## 工作台

工作台用于快速了解今天与接下来要做的事。

- **接下来**：按排序展示最多三条未完成的最近待办；没有日期的事项会标为“待安排”，可点击进入日历查看完整安排。
- **重要时间段**：展示正在进行或尚未结束的时间段、倒计时与起止时间。可视区与“接下来”保持三行高度，超过三条时可在右侧滚动查看。
- **最近待办**：适合记录近期要完成的事项。可勾选完成、编辑内容，带日期或时间的事项会显示对应日程。
- **长期待办**：适合放暂未确定日期的计划，方便持续保留和逐项完成。

## 日历

日历提供按月查看与管理日程的视图。

- 使用左右按钮切换月份，“今天”可快速回到当前日期。
- 点击日期空白处即可新建待办；点击已有待办或时间条可编辑。
- 带日期的待办会显示在对应日期格中，勾选状态与工作台同步。
- 多日的重要时间段会以连续色条显示；不同时间段使用不同的柔和颜色区分。
- 时间条会按照开始和结束时间反映半天范围：晚于中午开始时从当天中部起，不晚于中午结束时在当天中部结束；开始处会显示开始时刻，结束当天的末尾会显示结束时刻。
- 同一周出现较多时间段时，日期行会自动增高，保证每条时间段都能清晰阅读。

## 日志

日志是按日期保存的私人手记。

- 可通过前后按钮或日期选择器切换页面。
- 标题和正文均会自动保存，无需手动提交。
- “时光倒流”会随机打开一篇已经写过的往日日志；可随时返回今天继续记录。

## 个性化设置

在“设置”中可以自定义使用体验：

- **主题设计**：提供蓝、绿、紫、黄、粉、橙、青与深色等主题；导航、强调元素和日历时间条会随主题协调变化。
- **字体设计**：可选择雅黑、圆体、宋体或楷体，并为中文、英文和数字匹配协调的字形。
- **字号大小**：在 90%–110% 范围内微调全站文字；相关事项行距也会随字号保持紧凑协调。
- **工作区背景**：可上传图片、选择用于右侧工作区的画面区域并调整缩放；系统会添加固定柔光层，保证文字清晰可读。

## 数据保存与隐私

朝夕目前是纯前端网页，所有待办、时间段、日志和个性化设置都保存在**当前设备、当前浏览器**的网站本地数据中，不会上传到服务器。

- 关闭网页或重新打开同一浏览器后，数据会继续保留。
- 更换设备或浏览器、使用无痕窗口，或清除该网站的浏览器数据后，内容无法自动恢复。
- 在线版与本地调试版的保存位置彼此独立。

重要内容建议另行备份。
