# 朝夕

一个简洁的个人日程、待办与日志工作台。数据默认保存在当前浏览器本地，适合轻量的个人使用。

## 在线使用

直接打开：[https://yaohuan1120.github.io/zhaoxi/](https://yaohuan1120.github.io/zhaoxi/)

无需下载、安装或运行命令。首次在某个浏览器打开时会建立该浏览器自己的本地数据。

## 功能

- 最近待办与长期待办
- 日历查看、编辑与勾选同步
- 重要时间段倒计时
- 每日日志与“时光倒流”回顾
- 离线优先的纯前端实现

## 本地开发

如果你想修改源代码或在电脑上调试，可直接用浏览器打开 `index.html`，或在项目目录执行：

```bash
python -m http.server 4173
```

随后访问 `http://localhost:4173`。

## 数据说明

目前的数据保存在浏览器的 Local Storage 中，数据键名为 `zhaoxi-planner-v1`。它存放在浏览器的个人资料目录里，不是项目文件夹中的独立文件，也不会上传服务器。

- 在线版的数据归属于 `https://yaohuan1120.github.io`；本地开发版的数据归属于 `http://localhost:4173`，两者彼此独立。
- 数据会留在当前浏览器与当前设备中；换浏览器、换设备、使用无痕窗口或清理该网站的浏览器数据后，不能自动找回。
- 因此它适合离线个人使用；重要内容建议另行备份，后续也可以在此基础上接入云端同步。
